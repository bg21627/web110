For the first activity, I did the LearnFree Internet Safety and TutorialsPoint Internet Security tutorials. The topic was online threats and how to stay safe. I learned that many attacks work by tricking people, like phishing emails and fake links, rather than hacking computers directly. I also learned about different kinds of malware, like viruses and worms. Since I want to work in radiology, I'll handle private patient information, so knowing how to spot a fake email will help me keep it safe. In the web browser safety activity, I looked at my browser's privacy and security settings. I learned that my browser saves a lot about me, like cookies, history, and autofill info. I also learned that a website's certificate shows that the site is real and secure. Private browsing only stops my browser from saving my history, but websites and my internet provider can still see what I do. At a hospital, computers are shared, so I will make sure to log out and not save my passwords. For the anti-malware activity, I scanned my computer and tested it with the EICAR test file. I learned that the EICAR file is fake malware that is totally harmless, so it is a safe way to check if antivirus is working. I also learned that antivirus only works well if it stays updated. Hospitals can get hit by ransomware, which can delay patient care, so I will take security warnings seriously and report problems right away. When I researched password managers and multi-factor authentication, I learned that using the same password everywhere is risky because one leak can unlock all my accounts. A password manager creates and saves a strong password for every site, so I only have to remember one. Multi-factor authentication adds an extra step, like a code sent to my phone. Hospitals often use this to log into patient records, so I will already know how it works. I also plan to use it on my email and bank accounts.
