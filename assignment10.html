Assignment 10

In this session, I learned how CSS controls the way a web page looks, while HTML only controls its structure. I practiced the three ways to add CSS: inline styles that change a single element, internal styles placed in the head of one page, and an external style sheet that can format every page on a site at once. I also learned that the closer a style is to the element, the more priority it has, so inline CSS overrides internal CSS, and internal CSS overrides the external file. Creating one style.css file and linking it to all of my web110 pages showed me how much time an external sheet saves, because one change updates the whole site. Since I am going into radiology, I will not be designing websites, but the idea of keeping things consistent and separating content from appearance still applies. Radiology reports and imaging software use standard layouts so that doctors can find information quickly, and understanding how formatting works behind the screen will help me make sense of the systems I use and notice when something is not displaying correctly.
