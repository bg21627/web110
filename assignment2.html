For this session I completed three activities from the Web Browsers lesson. I learned a lot about how browsers work and how I can use that in my own projects. Activity 1: Install and Compare Multiple Browsers The first activity I completed was installing and comparing multiple browsers. The topic here is how different browsers show the same web page. What I learned is that each browser uses its own engine to load a page, so the same site can look or act a little different depending on which one you open. I also learned that browsers do not all start with the same privacy settings, so what one browser blocks by default another might allow. I can apply this to my own environment because I build and run my own website. Now I know I should open my site in more than one browser before I share it, so it works well for every visitor and not just for me. Activity 2: Configure Browser Settings The second activity was configuring browser settings. The topic is the options a browser gives you, like the home page, cookies, and the cache. What I learned is that the cache saves copies of pages so they load faster the next time, and cookies store small pieces of data about you and your visits. I also learned that the user has a lot of control over privacy and security in the settings, more than I realized before. I can apply this because when I change something on my site and the update does not show up, it is usually the cache holding an old copy. Clearing the cache or using a private window lets me see the real, current page while I work on it. Activity 3: Configure Extensions and Add-ons The third activity was configuring extensions and add-ons. The topic is the small programs you can add to a browser to give it more features. What I learned is that extensions can be really helpful, but they can also see and change almost everything the browser does, so a bad one is a real security risk. I can apply this in two ways. I can use developer extensions like color pickers and page inspectors to build my pages faster, and I can also be careful about what I install, since I use the same computer to sign in and manage my store. Overall, these activities helped me understand browsers from the inside. The comparison work helps me test my site, the settings work helps me fix problems faster, and the extensions work helps me build faster and stay safer. All of this fits the web projects I am already working on.
