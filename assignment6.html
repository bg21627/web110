The first activity I completed was Internet Services, which covered the different kinds of services the internet provides. I learned that these services fall into a few main groups, including communication services like email and chat, information retrieval services like FTP, web services that let applications talk to each other, and the World Wide Web. Before this, I thought of the internet and the web as the same thing, so it helped to see that the web is only one service running on top of the internet. I can apply this by picking the right tool for what I am trying to do instead of using a browser for everything. It also gives me the right vocabulary to use as I move toward a career in technology. The second activity was FTP, and the topic was the File Transfer Protocol. I learned that FTP is a standard way to move files between a client and a server, and that it uses one connection for commands and a separate one for the data. What surprised me is that regular FTP sends the username and password in clear text, which is why secure versions like FTPS and SFTP exist. I also learned that most modern browsers no longer support FTP, so you usually need a dedicated FTP client. Right now I publish my class pages through GitHub, but many web hosting companies have you upload site files with FTP or SFTP. If I build a site on a regular web host in the future, I will know to use the secure option. The third activity was Intellectual Property, and the topic was music piracy and the legal issues around illegal peer-to-peer file sharing. I learned that peer-to-peer technology and file sharing are not illegal by themselves. The problem is sharing copyrighted material without permission. The penalties are a lot bigger than I expected. Civil damages can run from $750 to $30,000 for each work, and up to $150,000 for each work if it was done on purpose. Criminal cases can bring up to five years in prison and fines up to $250,000. I also learned that files from peer-to-peer networks can carry viruses and spyware. I can apply this by sticking with legal services for music and movies. As a web student, I will also make sure the images, music, and code I put on my pages are my own or something I have permission to use.
