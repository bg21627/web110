Assignment 1 - Learning Summary

Glenn Bernales

The first thing I worked through was the Internet Fundamentals reading, which covered what the internet actually is and how it works. I have always used the internet without really thinking about what was happening behind it, so it was interesting to learn that it is basically a giant network of networks and that no single company or person owns it. What stuck with me most was how data gets broken into small pieces called packets, and how a client, like my laptop, requests information while a server sends it back. I can apply this by being a smarter, more aware internet user and by building on it as I move toward a career in technology. Even just understanding what an IP address and a server are makes the rest of this course feel less intimidating.

The second activity was creating my own GitHub account. Before this, I had heard the name GitHub but had no idea what it was for. I learned that it is a platform developers use to store their code online and keep track of changes over time, which is called version control. What surprised me is that it is not only for professional programmers; it is something a beginner like me can actually start using right away. I can see myself applying this by using GitHub to save all of my class projects in one safe place instead of losing files on my computer. In the future, if I work in web development, having a GitHub account is almost expected, so getting comfortable with it now feels like a head start.

The third activity was creating my first repository along with a README and a web page. A repository is basically a project folder that lives online, and I learned that GitHub can even turn one into a live website that anyone can visit. That honestly felt pretty cool, because I made something and it now exists on the actual internet. Writing the README also taught me a little about documenting a project so that other people, and future me, can understand what it is. I can apply this by using repositories to organize every assignment in this course, and down the road I could use the same skill to host a personal portfolio or hobby website. It made web hosting feel a lot more doable than I expected.
